## 1. 问题动机：前瞻距离两难困境

端到端 RL 导航策略的观测里目标编码为 `[d_x, d_y, d_z, ln(dist+1)]`，线速度与 `ln(dist+1)` 正相关。
固定前瞻距离无法同时满足"开阔区高速避障"与"窄门顺畅穿行"：

```
                      前瞻距离两难困境 (Dilemma)
                                │
        ┌───────────────────────┴───────────────────────┐
        ▼                                               ▼
【大前瞻 L=2.0m】                               【小前瞻 L=0.5m】
优点：决策视界深远，提前平滑避障，              优点：胡萝卜点落在门缝正中央，
      线速度拉满 (0.8~1.0 m/s)。                    目标向量直穿门洞，不撞门框。
缺点：过窄门时目标穿透门框射入侧墙，            缺点：ln(dist+1) 骤降引致速度衰减至 0.2m/s；
      诱发强烈碰撞惩罚，掉头逃逸拒进门。            开阔区视界过窄，丧失动态避障反应距离。
```

大前瞻拒进门的根因是"隔墙指路"：门前提前 0.5m 时 L=2.0m 的胡萝卜点已延伸至门后 1.5m，
机器人机头微偏 10~15°，机身坐标系下目标向量就会穿过门框侧墙，价值函数的碰撞惩罚占优，
策略宁可掉头探索也不进门。小前瞻则让 ln(dist+1) 从 1.1 跌到 0.4，速度被压到爬行，
且决策视界只剩 0.25m（小于车体长度 0.6m），无法完成绕障。

进一步地，真实工况常见"直行一段后直角转弯穿门"，机身视角盲区 + 切内角相撞 + 门内出画失盲
都要求算法具备跨地图自适应的几何前向预判与感知状态锁存。

## 2. 算法架构与数据流

自适应算法模块化分层设计：

```
[几何层 Path 空间域]
  /global_path 折线 → 正交投影 s_curr → 滑动窗口 [s_curr, s_curr+D_win]
  → 累计折角 ΔΘ → L_curv (余弦插值)

[感知层 深度流]
  ZED 2i 深度图 40×64 → ROI 中段 (35%~70%) → 列中值投影 d_col
  → 三区域门洞启发式 → IsNarrowDoor
  → 空间迟滞锁存器 (Passage Latch): 锁存后 Δs < 1.2m 强制 L_clear = 0.5m

融合：L_raw = min(L_curv, L_clear)
非对称 Slew-Rate 限幅：收缩 2.5 m/s（快），恢复 0.8 m/s（慢）
→ 插值生成动态胡萝卜点 → ONNX 策略推理
→ 门洞航向对齐检测 (|yaw_err| < 20°) → 窄门保底前向速度补偿
```

---

## 3. 模块一：Path 前向滑动窗口曲率因子 L_curv

传统算法只算机器人当前位置曲率，高速时有严重滞后。本算法提出**前向探查滑动窗口**：
无论机器人身处何处，始终向前探查未来 `D_window`（默认 1.6 m）路径段的几何形状，
只要前方即将转折，在进入拐弯前 ~1.0 m 就提前把前瞻平滑收紧。

离散折线解析：设路径点 P_0..P_N，当前投影弧长 s_curr，探查区间 [s_curr, s_curr + D_window]。
对每条线段求交集 Δs_i，提取切向航向 θ_i，计算窗口内航向夹角差 δθ_i，综合转向活跃度：

```
ΔΘ = max( Σ|δθ_i|, |θ_last − θ_first|, max_i |δθ_i| )
```

余弦平滑映射（θ_low=20°，θ_high=50°）：

- ΔΘ ≤ 20° → L_curv = L_max (2.0m)
- ΔΘ ≥ 50° → L_curv = L_min (0.5m)
- 中间 → 余弦插值，导数连续无阶跃

工程效果：直行走廊行进时距离右转小门尚有 1.0m，探查窗口已将门处 90° 直角弯计入 ΔΘ，
前瞻由 2.0m 提前下降到 0.5~0.75m，机器狗以紧凑前瞻贴紧圆弧转弯，避免大前瞻切弦撞门框内侧。

## 4. 模块二：局部通道净空感知与空间迟滞锁存 L_clear

### 4.1 深度图 ROI 与列向降维

输入 ZED 2i 深度图 D ∈ R^{H×W}（40×64）。

1. 剔除地平与天花板：ROI = D[⌊0.35H⌋ : ⌊0.70H⌋, :]
2. 列中值投影：d_col[j] = nanmedian(ROI[:, j])

### 4.2 三区域门洞启发式分类

视场均分左/中/右三区。双侧近场立柱判据：min(d_col[Left]) < 1.4m 且 min(d_col[Right]) < 1.4m。
中央通道开阔判据：d_center = median(d_col[Center])，若 d_center 明显深于两侧立柱
（d_center > min(d_left, d_right) + 0.25m）或中央为远端开阔平原，则触发门洞判定：
IsNarrowDoor = True，W_clearance ≈ 0.85m。

### 4.3 空间迟滞锁存器（Passage Spatial Latch）

致命痛点：机器狗行进至门框前 0.2m 时，两侧门框因视角扩展移出相机横向画面（出画），
单帧感知此时测得全视野开阔，若无锁存，前瞻会在跨入小门瞬间突增到 2.0m，引发门框撞击。

空间锁存机制：
1. 一旦检测到进入窄道（IsNarrowDoor = True），锁存当前沿线累积进度 s_entry = s_curr，置 in_narrow = True；
2. 持续跟踪已通过弧长 Δs = s_curr − s_entry；
3. 只要 Δs < D_latch（默认 1.2m，大于车体长度两倍），即便深度相机完全看不到立柱，
   也强制保持 L_clear = L_min = 0.5m；
4. 只有累计穿过 1.2m、整车完全脱离门套结构后，才安全释放锁存。

## 5. 模块三：非对称 Slew-Rate 限幅与双因子融合

### 5.1 保守融合（Min-Fusion）

曲率因子表征轨迹转折压迫，净空因子表征物理环境压迫：

```
L_target = min(L_curv, L_clear)
```

- 只要前方有急弯，**或者**当前身处窄门，前瞻均果断压低到 0.5m；
- 只有既无急弯又是大平原时，前瞻才允许放大到 2.0m。

### 5.2 非对称 Slew-Rate 限幅

目标前瞻 L_target 发生阶跃跳变时，胡萝卜点会在全局路径上剧烈瞬移，导致策略输入的目标向量夹角突跃、机身转向甩尾。
非对称变化率限幅器：

- Δt = clamp(t_curr − t_last, 0.001s, 0.5s)
- 若 L_target < L_{t-1}（收缩）：L_t = max(L_target, L_{t-1} − R_down·Δt)，R_down = 2.5 m/s
- 若 L_target > L_{t-1}（回弹）：L_t = min(L_target, L_{t-1} + R_up·Δt)，R_up = 0.8 m/s

从 2.0m 降至 0.5m 仅需 0.6s，能敏捷化解突发弯道与近身障碍；
出关后从 0.5m 缓慢平滑升至 2.0m 耗时约 2.5s，保证出关加速平稳，无前倾冲撞。

## 6. 模块四：航向对齐窄道前向推力补偿

当 L=0.5m 时，策略网络因 ln(1.5)≈0.405 自然输出爬行速度（0.15~0.25 m/s）。
在控制器命令发布阶段（`rl_nav_controller_adaptive.py`）：

1. 检查是否处于窄门穿行锁存状态：in_narrow == True；
2. 提取机身体系下目标向量横纵分量 [t_x,b, t_y,b]，计算航向对准偏差 yaw_err = atan2(t_y,b, t_x,b)；
3. 安全补偿条件：当 |yaw_err| < 20°（≈0.35 rad）时，证实机头已精准正对门缝，
   若此时网络输出的未滤波线速度 v_x < v_boost（默认 0.35 m/s），则强制将基底线速度提升至 v_boost：
   v_x,cmd = max(v_x,cmd, v_boost)。

实机效果：机器狗在拐弯后机头一旦对正小门，不会在门前迟疑爬行，而是以干脆稳健的
0.35~0.45 m/s 顺畅穿门而过。

> 注意：门速度保底在楼梯上严格禁用（`rl_nav_controller_stairs.py` 里 `not is_stair_down and not is_stair_up` 才生效）。

## 7. 算法参数全表

| 参数 | 代码变量 / CLI | 默认值 | 单位 | 物理含义与调优准则 |
|---|---|---|---:|---|
| 前瞻下界 | `lookahead_min` | 0.4（sru-local 部署默认；代码 declare 默认 0.5） | m | 窄门与急弯前瞻。过大易穿墙，过小易造成速度损失。建议 0.4~0.6 |
| 前瞻上界 | `lookahead_max` | 2.0 | m | 开阔区巡航前瞻，决定了平原最高航速与预判视界。建议 1.8~2.5 |

| 急转折角阈值 | `turn_angle_high_deg` | 50.0 | ° | 超过此转角认为存在直角或急弯，前瞻降至 L_min |
| 收缩变化率 | `slew_rate_decrease` | 2.5 | m/s | 前瞻从大到小的最大变动速率，要求快速响应，一般 2.0~3.0 |

| 过门推力补偿 | `door_speed_boost` | 0.35（节点默认）/ 0.0（`start_nav.sh` 部署默认） | m/s | 门内航向对齐后的保底前向速度。过大进门冲撞，过小蠕动，建议 0.3~0.4。**部署默认关闭** |
| 清净度阈值 | `clearance_threshold` | 1.05 | m | 触发门洞判定的净空宽度阈值 |

- **测试平台**：Unitree Go2W（实机）
- **测试路段与工况**：当前位置至电梯间路段（长直道走廊、直角/转弯穿窄门、下行长楼梯混合地形）
- **测试模式**：消融对比（`curv-only` 路径曲率单因子 vs `door-only` 视觉净空单因子）

### 9.1 实测现象与消融对比结论

| 测试模式 | 启动方式 | 直路避障与巡航表现 | 转弯过窄门表现 | 长楼梯通行表现 |
|---|---|---|---|---|
| **`curv-only`**（仅 Path 曲率转弯判断） | `./start_nav_adaptive.sh --curv-only` | **表现更优**：开阔直道前瞻稳定在 2.0m，视界深远；彻底消除了视觉噪点/走廊立柱导致的假门洞误锁存与突发减速 | **稍有影响，易碰窄门**：转弯过窄门时容易剐蹭门框，需进一步审查曲率与前瞻收缩判定逻辑 | **无法通行**：遇长阶梯无法顺利向下行进 |
| **`door-only`**（仅视觉窄门净空感知） | `./start_nav_adaptive.sh --door-only` | **难以有效避障**：视觉极易将走廊侧墙、普通立柱或地面反光误触发为"假门洞/通道收敛"，导致前瞻频繁跌至 0.5m 并陷入 1.2m 锁存，决策视界过窄，避障不及 | **进门能感知但稳定性差**：正对门洞时能收缩前瞻，但受光照、相机视场与角度漂移影响波动大 | **无法通行**：遇长阶梯无法顺利向下行进 |

### 9.2 关键根因剖析与后续迭代待办

#### 1. `curv-only` 模式下"转弯过窄门易碰门框"的判定逻辑排查
- **现象归因**：
  - 窗口收缩滞后或恢复过快：当前滑动窗口 D_win = 1.6m。转弯进门时，当机身刚转过直角弯、机头进入门缝瞬间，未来 1.6m 路径已变为房间内直线，导致窗口有效折角 ΔΘ 骤降，前瞻点开始以 R_up = 0.8 m/s 回弹增大，拉长的前瞻在门套后方再次形成"割线"，牵引机身后侧刮蹭门框；
  - 缺乏物理空间贴合先验：纯折线几何无法感知机器人与门框左右两柱的实际毫米级物理净距，当全局规划折线与物理门缝中心存在轻微横向偏移（5~10cm）时，纯几何跟踪缺乏侧向柔顺避让。
- **排查与改进方向（TODO）**：
  - [ ] 审查 `compute_path_curvature_lookahead` 中转角平滑余弦映射区间的上下限（当前为 20° ~ 50°），确认急弯触发前瞻收敛的时机；
  - [ ] 针对"转弯后立即过门"的工况，增加出弯后的前瞻恢复延时或距离滞后（过弯后持续保持小前瞻穿门一定弧长再恢复）；
  - [ ] 校验全局规划器给出的门洞折线是否精准穿过门套几何中轴。

#### 2. "直路避障效果更好"与"视觉误触发"的本质认知
实测证实了此前工程判断：**视觉单帧投影法在直道存在结构性缺陷**，将走廊边缘误判为窄门是导致直路避障能力崩溃的元凶；因此直道巡航应果断以纯几何/开阔大前瞻（2.0m）为主导。

#### 3. "长楼梯地形仍无法通行"的深层原因
- **深度感知视角与几何截断**：为了过滤地面起伏噪声，截取了深度图纵向 35%~70% 的 ROI。当下长楼梯时，阶梯向下断崖式跌落，该截取区域内大量测距超出有效范围或返回无限远（Inf/NaN），导致前向深度感知"失明"；
- **高程落差与步态适应**：当前高层规划与前瞻提取主要工作在 2D 平面投影弧长上，未针对陡峭 3D 楼梯高程阶梯建模；同时底层强化学习策略网络主要基于平面及微起伏地形训练，面对长下行阶梯产生俯仰角突变并诱发策略失稳拒止。下楼梯工况需要专门的阶梯感知与特化步态/控制策略接管（见 `GO2W_NAVIGATION_SYSTEM_GUIDE.md` 的楼梯坡度门控方案）。

## 10. 诊断工具

门区导航诊断记录器：`diagnostics/door_diagnostic_logger.py`。

```bash
python3 ~/go2w_nav_ros2_ws/door_diagnostic_logger.py pass_0.5m
python3 ~/go2w_nav_ros2_ws/door_diagnostic_logger.py fail_2.0m
```

每次录制在 `~/door_diagnostics/` 下生成独立 `session_YYYYMMDD_HHMMSS[_tag]/` 目录，含：
- `heatmaps/*.png`：伪彩色深度热力图（320×200），标有门洞中央检测窗口、前瞻目标方向与夹角、实时控制速度 [vx, wz]、门洞正中深度；
- `depth/*.npy`：网络实际输入的 40×64 原始浮点深度矩阵，用于离线送入 VAE 评估隐空间表征；
- `meta/*.json`：单帧里程计位姿、全局前瞻点坐标、相对机器人航向角误差等诊断元数据；
- `trajectory.csv`：全过程时序一览表（时间戳、机器狗位姿、前瞻点坐标、距角、控制指令、门中净深）；
- `session_summary.json`：总帧数、录制时长、平均帧率、丢包统计。

记录器内部采用**异步非阻塞写盘队列**与**目标离线保护**：目标点短暂丢失或停滞时深度图仍持续录制；按 Ctrl+C 优雅退出并保存概况。
