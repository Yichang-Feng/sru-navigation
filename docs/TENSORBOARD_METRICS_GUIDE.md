## 1. 核心速度指标对比

这两个指标共同描绘了机器狗在二维平面上的运动效率与意图对齐度。

```
           目标点 G (Goal)
              ^
              |  方向向量 u_goal
              |
              |     / 实际速度向量 v_2d (模长: velocity_magnitude)
              |    /
              |   /  夹角 θ
              |  /
              | /
              +----------------->
            机器狗当前位置 R
              |
              +---> 投影长度: velocity_toward_goal = |v_2d| * cos(θ)
```

### 1.1 `Metrics/robot_goal/velocity_magnitude` (全向运动合速度)
* **物理含义**：机器狗质心在世界坐标系水平地面（X-Y 平面）上的**线速度绝对大小（模长）**，不论其朝向哪个方向运动。
* **代码定义**（`goal_commands.py` L615-617）：
  $$\text{velocity\_magnitude} = \|\mathbf{v}_{2\text{D}}\| = \sqrt{v_x^2 + v_y^2}$$
* **单位**：$\text{m/s}$。
* **理想状态**：
  * **初期 (0~30 轮)**：$0.3 \sim 0.5\text{ m/s}$（盲目探索或抖动）。
  * **中期与收敛期**：稳定在 $0.4 \sim 0.8\text{ m/s}$（受限于高层指令缩放 `policy_scaling`，Phase 1 设定限速为 $1.5\text{ m/s}$，由于需要转弯避障，平均合速度通常在 $0.5 \sim 0.7\text{ m/s}$ 属优良步态）。
* **异常诊断**：
  * $< 0.1\text{ m/s}$：机器狗卡死或原地瘫倒；
  * $> 1.8\text{ m/s}$：步态出现轮部打滑或物理飞车爆散。

### 1.2 `Metrics/robot_goal/velocity_toward_goal` (向目标有效投影速度)
* **物理含义**：机器狗的水平速度向量在**目标点视线连线方向上的标量投影（有效位移速率）**。
* **代码定义**（`goal_commands.py` L619-620）：
  $$\mathbf{u}_{\text{goal}} = \frac{\mathbf{p}_{\text{goal}}^{xy} - \mathbf{p}_{\text{robot}}^{xy}}{\|\mathbf{p}_{\text{goal}}^{xy} - \mathbf{p}_{\text{robot}}^{xy}\|}$$
  $$\text{velocity\_toward\_goal} = \mathbf{v}_{2\text{D}} \cdot \mathbf{u}_{\text{goal}} = \|\mathbf{v}_{2\text{D}}\| \cos(\theta)$$
  其中 $\theta$ 是实际前进速度与目标连线的夹角。
* **单位**：$\text{m/s}$。
* **符号含义**：
  * **正数 ($>0$)**：机器狗正在逼近目标点；
  * **负数 ($<0$)**：机器狗正在背离目标点逃跑或倒车；
  * **为零 ($=0$)**：机器狗静止不动，或者在围绕目标点做纯粹的切向圆周运动。
* **理想状态**：
  * **初期**：负值或极小微弱正值（$-0.05 \sim 0.05\text{ m/s}$，盲目乱窜）；
  * **收敛期**：**持续稳定正值 ($0.05 \sim 0.25\text{ m/s}$)**。
  * *注：为什么平均投影速度通常在 0.1 左右而不是 1.0？* 因为机器狗在快到终点减速、转向调整、避障绕行以及停在目标圈内时投影速度都会降为 0，全局平均统计值在 $0.05 \sim 0.15\text{ m/s}$ 即代表极高效率的直扑目标。

### 1.3 两者结合分析（导航运动效率比 $\eta$）
$$\eta = \frac{\text{velocity\_toward\_goal}}{\text{velocity\_magnitude}} = \cos(\theta)$$
* 若 $\text{magnitude}$ 很大但 $\text{toward\_goal} \approx 0$：说明机器狗在**高速画圆或无头乱撞**；
* 若两者数值相近且均为正：说明机器狗正在**笔直冲向目标**，导航轨迹极其笔直高效。

## 2. 导航任务表现指标 (`Metrics/robot_goal/*`)

| 指标名称 | 含义 | 代码定义 | 理想状态 |
| :--- | :--- | :--- | :--- |
| `success_rate` | **导航任务到达成功率** | 滑动窗口内触发终点半径（$0.5\text{m}$）的回合占比 | **$> 90\%$**（越快达到越好，当前 Phase 1 在 60 轮达到 90%+ 属于优秀） |
| `velocity_magnitude` | 质心水平合速度 | $\sqrt{v_x^2 + v_y^2}$ | $0.4 \sim 0.8\text{ m/s}$ |
| `velocity_toward_goal` | 向目标有效投影速率 | $\mathbf{v}_{2\text{D}} \cdot \mathbf{u}_{\text{goal}}$ | 正数，稳定在 $0.05 \sim 0.25\text{ m/s}$ |

## 3. 奖励项详解 (`Episode_Reward/*`)

> **注意**：TensorBoard 中展示的数值是该奖励项经过权重加权后的**每步单回合均值**。

| 奖励项名称 | 权重 | 含义与设计目的 | 理想曲线形态 |
| :--- | :--- | :--- | :--- |
| `progress` | `+1.5` | **势能引导奖励**：按前后两步距离差计算 $(d_{t-1} - d_t) / \Delta t$。提供密集正向梯度。 | **稳定在 $+0.3 \sim +0.4$**。只要在往终点走，就会稳定为正。 |
| `heading` | `+0.3` | **航向对齐奖励**：机体正前方向量与目标方向的余弦值 $\cos(\phi)$。 | **逐渐爬升并稳定在 $+0.04 \sim +0.1$**。正值代表机头正对目标。 |
| `reach_goal` | `+10.0` | **到点稀疏奖励**：进入 $0.5\text{m}$ 目标圈时触发。 | **快速上升到 $+0.6 \sim +0.7$**，与 `success_rate` 严格正相关。 |
| `time_cost` | `-0.01` | **每步时间成本**：每步恒定扣除 0.01。惩罚拖延与慢走。 | 稳定在 $-0.002 \sim -0.003$。 |
| `action_rate_l1` | `-0.02` | **动作变化率惩罚**：$\|a_t - a_{t-1}\|_1$。抑制高频控制抖动。 | $-0.01 \sim -0.05$。数值越平缓说明控制指令越丝滑。 |
| `lateral_movement` | `-0.02` | **横向侧移惩罚**：$|v_y|$。引导机器狗多正向行驶、减少横移漂移。 | 维持在 $-0.005 \sim -0.02$。 |
| `rot_movement` | `-1e-5` | **自旋角速度惩罚**：$\|\omega_z\|_2$。防止无意义的原地打转。 | 极小负值（约 $-1e-5$）。 |
| `joint_acc_l2_joint`| `-1e-7` | **关节加速度阻尼**：腿部与轮部关节加速度的二范数惩罚。保护电机。 | $-1e-4 \sim -1e-6$。 |
| `episode_termination` | `-50.0`| **灾难性终止惩罚**：撞墙、跌落、翻滚时施加的大额惩罚。 | **无限趋近于 0**（撞击跌落越少，该惩罚越少）。 |
| `backward_movement_penalty` | `-1.0` | **倒车惩罚**：仅在深度相机正向朝前时对负向 $v_x$ 惩罚。 | 维持在 $-0.01 \sim 0.0$。 |

## 4. 回合终止原因统计 (`Episode_Termination/*`)

该组指标是排查策略失败原因的最直接依据（各项值表示该类终止在当前采集环境中的比例）：

| 终止项名称 | 触发物理条件 | 理想状态 | 异常排查提示 |
| :--- | :--- | :--- | :--- |
| `early_termination` | **成功到达目标**（进入目标 $0.5\text{m}$ 触发） | **$> 0.90$** | **注意：此项在代码中代表“成功通关”！** 越高越好。 |
| `time_out` | **超时**（达到 300 步/60 秒仍未抵达目标） | **$0.000$** | 若高居不下，说明策略卡死在原地或迷失在迷宫中。 |
| `base_contact` | **碰撞**（机身 base、大腿 hip 受到 $>1.0\text{N}$ 撞击） | **$< 0.05$** | 若偏高，说明感知避障不足，撞墙或绊倒在台阶上。 |
| `large_pitch_angle` | **翻倒**（机身俯仰角 $> 40^\circ$） | **$0.000$** | 若出现正值，说明下层运动底盘失稳或在斜坡上后仰侧翻。 |
| `terrain_fall` | **跌落坑洞**（机身高度低于阈值 $-0.35\text{m}$） | **$0.000$** | 在 Phase 1（平地）应恒为 0；在 Phase 4（坑洞）需重点监控。 |

## 5. 优化与损失函数指标 (`Loss/*`)

| 损失项名称 | 算法含义 | 理想状态 |
| :--- | :--- | :--- |
| `value_function` | 价值网络（Critic）对未来总折扣回报的均方误差（MSE Loss） | **先升后降，平缓收敛**（通常在 $0.05 \sim 0.5$ 区间平稳震荡，不发散即可）。 |
| `surrogate` | PPO 策略网络（Actor）的重要性采样裁剪目标损失 | 在 $0.0$ 附近微幅波动（$-0.01 \sim +0.01$），反映单次更新的策略改变量。 |
| `kl_divergence` | **MDPO 专属指标：Policy 1 与 Policy 2 之间的双向 KL 散度** | **稳定在 $0.005 \sim 0.02$**。表明两套网络既有独立探索差异，又保持着健康的相互蒸馏牵引。 |
| `learning_rate` | 当前优化器学习率（Learning Rate） | 按照指数调度（`exponential`）平滑从 $1.0\times 10^{-3}$ 下降到 $1.0\times 10^{-5}$。 |

## 6. 策略与探索诊断指标 (`Policy/*`)

### `Policy/mean_noise_std` (高斯动作分布标准差 $\sigma$)
* **物理含义**：Actor 策略网络在连续速度动作空间（$v_x, v_y, \omega_z$）输出分布的随机探索噪声标准差。
* **理想曲线形态**：
  * **初期 (0~50 轮)**：从初始值 $1.0$ 缓慢自然回落至 $0.8 \sim 0.9$；
  * **中期 (50~500 轮)**：维持在 **$0.6 \sim 0.85$**，保持充分的避障与路径探索多样性；
  * **后期 (1000+ 轮)**：逐步收敛至 $0.3 \sim 0.5$，形成确定、精准的高品质导航轨迹。
* **致命陷阱（警惕坍塌）**：
  * **病态**：如果前 100 轮快速断崖式下跌至 $<0.3$，说明策略因缺乏正向反馈而陷入“摆烂死锁”，方差坍塌；
  * **防护**：当前代码底层已加入 `log_std.clamp(min=-2.5, max=0.2)`，杜绝了后期发散与早熟坍塌。

## 7. 训练概览与计算吞吐 (`Train/*` & `Perf/*`)

### 7.1 `Train/mean_episode_length` (平均单回合存活步数)
* **物理含义**：环境智能体从复位到回合终止所经历的平均交互步数（单步高层时间 $\Delta t = 0.2\text{s}$）。
* **理想趋势解读**：
  * **第一阶段 (0~10 轮)**：极低（10~30 步），大量狗刚出生就因为碰撞或失稳死亡；
  * **第二阶段 (10~30 轮)**：大幅拉长（200~280 步），狗学会了平稳站立与求生，但还不会去终点，大量超时；
  * **第三阶段 (30+ 轮，成功率爆发)**：**迅速缩短并稳定在 $70 \sim 95$ 步（约 14~19 秒）**！
  * **为什么变短是好事？** 因为最大回合限制是 300 步（60秒）。步数缩短到 80 步，意味着机器狗**以最快速度直扑终点提前成功通关**，而不是在场地上拖延时间。

### 7.2 `Train/mean_reward` (单回合累积总回报)
* **物理含义**：智能体在一个完整回合内获取的所有加权奖励代数和。
* **理想状态**：随着 `success_rate` 提升，从早期的负数（碰撞惩罚占主导）一路单调上升至 $+50 \sim +80$。

### 7.3 `Perf/total_fps` (仿真与训练吞吐速率)
* **物理含义**：物理仿真器加神经网络前后向推理每秒处理的总步数（Frames Per Second）。
* **健康区间**：在 1024 个并行环境下，RTX 4090 / 专业 GPU 上的吞吐通常在 **$1400 \sim 1800\text{ FPS}$** 之间。
