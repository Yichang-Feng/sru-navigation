Unitree Go2W 局部导航控制器 · 状态变化图 (当前对齐标准)

由 rl_nav_controller（机载 RL 局部导航控制器）发布 · 状态机依据实时传感器、路径跟踪与指令事件判定

优先级与状态集合（6 状态体系，从高到低）

1stopped (停止/暂停) 2idle (空闲就绪) 3goal_reached (本段到达) 4failed (业务受阻死锁) 5error (硬件传感器丢失) 6running (自主推进中)

状态转移图 (6 状态全链路拓扑)

idle 空闲 running 运行中 goal_reached 本段到达 failed 业务遇阻 (可直接恢复) error 硬件异常 (拒绝新路径/需重启) stopped 暂停 (保留路径)

状态转移表（精确触发条件与恢复机制）

从到触发条件机体动作与恢复机制
idlerunning 收到新分段路径：/global_path（有效点集） 加载路径至折线跟踪器，前瞻胡萝卜点引导，ZED 深度自主避障
runninggoal_reached 机器人中心距离当前段终端点 < segment_arrive_threshold (0.15m) 主动刹停速度置零，清除已达路段，瞬发 1 次到达上报
goal_reachedidle 完成到达上报 瞬发后立刻变至 idle 空闲就绪（构成单向闭环三角）；在 idle 状态以 1Hz 广播心跳持续监听新路径，一旦收到新路径立即进入 running 推进
runningfailed 由于前方障碍物完全封堵，连续 blocked_timeout(4.0s) 进尺 < 0.1m 且线速度 < 0.1m/s 主动置零刹停避免死磕障碍物。
脱困恢复：上层重新下发绕行新路径或下发 resume 即可直接恢复 running，无需重启
failedrunning 上层下发避障新路径，或发送 /mission/control: "resume" 重置停滞检测器，恢复自主推进
runningerror ZED 深度相机连续丢帧超时 > camera_timeout (2.0s) 主动紧急制动刹停，防止无视觉盲跑撞击。
不可自动恢复：此时下发新路径会被主动拒绝，需检查硬件连接或重启机载终端
任意状态stopped 收到指令 /mission/control: "pause" 或手柄 ABORT 主动刹停底盘，自动在内存中保留未跑完路径与进度
stoppedrunning 收到指令 /mission/control: "resume" 且内存中有有效路径 若暂停期间收到过新路径则按新路径开始推进；若无新路径则从当前物理位置继续走完旧路径剩余路段

状态上报 JSON 格式与 msgs 规范一览（对齐 local_planner_status_diagram (1).html）

当前状态 (state)默认 msgs 内容兼容格式说明
idle[] (原生空数组)"[]", ""无路径任务，等待调度
running[] (原生空数组)"[]", ""自主避障循迹中
goal_reached[] (原生空数组)"[]", ""到达本段终点，等待下一段
failed[] (原生空数组)"[]", ""遇阻死锁（非致命，可脱困）
stopped[] (原生空数组)"[]", ""已暂停（路径保留在内存中）
error["zed_camera_lost"]'["zed_camera_lost"]', "zed_camera_lost"视觉传感器掉线（致命硬件故障）
示例：
正常/到达/遇阻：{"state":"goal_reached","msgs":[]} 或 {"state":"running","msgs":[]}
硬件故障：{"state":"error","msgs":["zed_camera_lost"]}

关键技术规范补充说明

  • msgs 兼容性：默认按照上层期望输出字符串中括号 "[]" 表示空列表；同时系统支持参数 --status-msgs-format 配置输出 "[]"、[] 或 ""，接收端亦完整兼容这几种格式的解析。
  • failed 与 error 严格分离：
    • failed：业务避障层面的受阻停滞，msgs 为 "[]"。无需重启，重发路径即可继续。
    • error：硬件层面的致命传感器丢失，msgs 为 "zed_camera_lost"。控制器主动拒绝新路径以保障安全，需重启或排查连线。
  • 心跳与瞬发：未变化时以 1Hz 周期广播；状态发生跳变时当个控制循环瞬时毫秒级发布。
  • 底盘总闸自动解锁：rl_nav_controller 启动且定位就绪后，自动发布 /startNavi: true 与 /motion_enabled: true 解锁底盘电机。
