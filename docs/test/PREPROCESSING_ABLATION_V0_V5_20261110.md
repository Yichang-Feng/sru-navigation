# 深度预处理消融 V0–V5（离线，2026-11-10 两组数据）

> 数据：`session_20261110_145214_realsense` 与 `session_20261110_150045_zed` 的原始深度 PNG（320 宽）
> 匹配：`analysis_20261110/matched_pairs.csv` 的 234 对位姿
> 工具：`scripts/depth_benchmark/reprocess_depth.py`
> 产出：`door_diagnostics/analysis_20261110/ablation/`（`report_ablation.md`、`ablation_metrics.csv`、`ablation_summary.json`、`variants_case.svg`、`variant_metrics.svg`）

---

## 0. 结论

1. **当前预处理 V0（无效像元 → `min_depth` + 直接 resize）把“近障碍”比例放大了 6–7.5 个百分点**：策略输入中 <0.8 m 的单元占比 RS 19.8% vs 真实 13.8%，ZED 30.0% vs 22.5%；并产生 1.3%/0.9% 的“假近”单元（策略看到 <0.8 m、真实 >1.5 m）。
2. **V2（最近有效值填充）是最优的即插即用改法**：近障碍比例回到 14.0%/24.1%（真实 13.8%/22.5%），假近单元降到 **0.0%/0.0%**，中心区最小距离从 0.16/0.58 m 恢复到 **0.98/1.19 m**（真实约 1.11/1.17 m），且保持 100% 覆盖。
3. **V1（填 0）不推荐**：虽然假近单元也少了，但 0 与近值插值后仍留下单像素假近（中心区最小 0.18/0.90 m），且跨相机分歧反而变大（Δcenter 0.74 m）。
4. **V3（中心裁剪）/ V4（letterbox）不能解决填充问题**，只是改变了 FOV；V4 还让近障碍比例略升。
5. **V5（虚拟相机对齐到仿真 FOV）跨相机分歧最小**（Δcenter 0.42→0.24 m、Δright 0.49→0.19 m、Δfloor 0.20→0.14 m），但**覆盖率只有 46.7%（RS）/70.5%（ZED）**——仿真 FOV（105.8°×79.1°）比两台相机都宽，虚拟网格外侧没有数据。V5 是 P1 的方向，但需要选一个折中的虚拟 FOV（例如两相机视场交集 ≈89°×58°）或给边界一个保守填充策略。

---

## 1. 方法

从原始深度 PNG 重建策略的 64×40 输入，变体：

| 变体 | 无效像元（0/NaN/`<min_depth`） | 几何 |
|---|---|---|
| V0_fill_min | → `min_depth`（现状） | 直接 resize 到 64×40 |
| V1_fill_zero | → `0.0`（开阔） | 直接 resize |
| V2_nearest_valid | → 最近的有效深度（distance-transform 孔洞填充） | 直接 resize |
| V3_center_crop | 同 V0 | 中心裁剪到 64:40（1.6）再 resize |
| V4_letterbox | 同 V0 | resize 到 64×36（保持角分辨率），上下补 0 到 64×40 |
| V5_virtual_cam | 同 V0 | 旋转对齐重投影到仿真虚拟相机（105.8°×79.1°，64×40） |

指标（234 对匹配位姿的均值）：

- `near08`：策略输入中 <0.8 m 的单元占比（分母为有效覆盖单元）；
- `real_near08`：同一网格里**真实有效深度** <0.8 m 的单元占比（只对 V0–V2 计算，几何一致）；
- `false_near`：策略输入 <0.8 m 但真实 >1.5 m 的单元占比；
- `center_min` / `right_min`：中心 ±20° / 右侧 20–40° 扇区的最小值（排除 0=开阔）；
- `floor_near`：底部中心 ROI 均值；
- `coverage`：V5 中有实际数据覆盖的单元占比。

读法：

- **V0 的 `near08` 明显高于 `real_near08`**（RS 19.8 vs 13.8，ZED 30.0 vs 22.5），差额就是填充/插值制造的假近。
- **V2 的 `near08` 与 `real_near08` 基本重合**（14.0 vs 13.8；24.1 vs 22.5），中心/右侧最小距离也回到真实量级（0.98/1.19 m vs 真实 1.11/1.17 m）。这是“策略输入忠实于真实几何”的直接证据。
- V1 的 `near08` 也接近真实，但 `center_min` 仍偏低（0.18/0.90 m）——0 与近值插值会留下单像素假近。
- V5 的 `center_min`/`right_min` 与 V2 同量级，但覆盖不全（见 2.2）。

| 变体 | Δcenter (m) | Δright (m) | Δfloor (m) | Δnear08 |
|---|---:|---:|---:|---:|
| V0 | 0.42 | 0.49 | 0.20 | 0.116 |
| V1 | 0.74 | 0.62 | 0.21 | 0.084 |

- **V2 把中心/右侧分歧减半**（0.42→0.29、0.49→0.16），且不损失覆盖；`Δfloor` 没有改善（0.22），因为 V2 不改变 FOV/近地盲区。

## 3. 推荐

### 立即（P0，改一行预处理）

**把无效像元填充从 `min_depth` 改为“最近有效值填充”**（V2）。实现要点：

1. `far_mask = depth > max_depth` 仍置 0（开阔）；
2. `close_mask = (depth <= 0) | (depth < min_depth)` 用最近的有效深度填充，而不是 `min_depth`；
3. 最近有效值用 `cv2.distanceTransformWithLabels`（一次 O(N)，Jetson 上 640×360 约 1–2 ms）；
4. 保持 `min_depth`/`max_depth` 不变，先单独改填充，再评估其他参数。

预期收益：假近单元 1.3%/0.9% → 0.0%/0.0%；近障碍比例回到真实值；中心/右侧最小距离回到 1 m 量级；跨相机 Δcenter/Δright 减半。**这不改变 FOV，也不增加延迟。**

### 下一步（P1，FOV 对齐）

V5 的分歧最小，但覆盖率不足。建议：

- 先做 **“两相机视场交集”虚拟相机**（约 89°×58°），保证 RS 100% 覆盖，再比较 Δaction 与覆盖率的折中；
- 或保留仿真 FOV，但把边界填成 `min_depth`（保守）或单独加一个“无效/未知”通道，避免 0（开阔）误导策略；
- 在虚拟相机层同时写入实测外参（ZED 比 RS 高 ~2.5 cm、靠后 ~2.5 cm）。

### 再下一步（L1 动作级验证）

V0 vs V2 的图像级差异已经清楚；下一步在补齐 `last_action`/`target_yaw_w`/`raw_action` 后，用 L1 回放比较 **同一状态下 V0 与 V2 的 Δaction**，确认“假近障碍减少”是否真的转化为更少的急转/停顿。

## 4. 局限

- **原始 PNG 是 320 宽**（RS 从 848×480 NEAREST 下采样，ZED 从 640×360 下采样），重建的 V0 与线上保存的 64×40 有差异：RS MAE 0.147 m / P95 0.601 m，ZED MAE 0.040 m / P95 0.108 m。因此本报告只做**变体间相对比较**，绝对值以线上 64×40 为准；V0 的绝对假近比例可能被低估/高估。
- **V5 是旋转对齐，忽略了两台相机 2.5 cm 的平移**；近距离会有少量视差误差。
- **V5 的像素级 MAE（0.52 m）不适合作为“对齐质量”指标**：它混合了真实深度差异、匹配位姿误差（均值 0.08 m）和近地视差；跨相机比较应看扇区统计的 Δcenter/Δright/Δfloor。
- `center_min`/`right_min` 是单像素最小值，对单个噪声点敏感；`near08`/`false_near`/`real_near08` 更稳健，建议以后者为主。
