## 一、 系统架构与核心机制

在四足轮足机器人（Unitree Go2W）执行长距离室内巡检与导航任务中，下楼梯属于典型的高危混合地形场景。本系统在原有强化学习端到端平面导航策略（`nav_policy.onnx`）的基础上，通过实车与离线消融实验，揭示并确立了**下楼梯控制的第一核心主导变量——前瞻点距离（Lookahead Distance, 0.40m）**。

实车与仿真实验表明：**是否对深度图进行虚拟坡道重映射，机器人均能平稳下楼；而一旦前瞻距离拉大至 2.0m，无论如何处理深度图均会导致避障拒止原地打转**。因此，系统实现了极简高效的解耦控制架构：

```
                    [上层全局规划器 (global_planner)]
                                   │ /global_path (3D Path)
                                   ▼
             ┌───────────────────────────────────────────┐
             │   AdaptivePathSegmentTracker (自适应前瞻)   │
             └─────────────────────┬─────────────────────┘
                                   │
              ┌────────────────────┴────────────────────┐
              ▼                                         ▼
   ┌───────────────────────┐                 ┌───────────────────────┐
   │    StairsSlopeGate    │                 │   Curvature/Clearance │
   │   (3D 路径坡度门控)    │                 │   (平地曲率与净空评估) │
   └──────────┬────────────┘                 └──────────┬────────────┘
              │ is_stair_down                           │ l_curv / l_clear

                                   ▼
                    [Go2W 机器人底盘 (/cmd_vel)]
```

## 二、 核心机理剖析：前瞻点对策略的决定性影响

### 1. 强化学习观测空间中的目标编码原理
导航策略网络（`nav_policy.onnx`）的观测空间中，目标点向量以相对本体坐标系的球坐标归一化形式输入：
$$\mathbf{p}_{\text{target}} = \left[ \frac{\Delta x_b}{d}, \frac{\Delta y_b}{d}, \frac{\Delta z_b}{d}, \log(d + 1) \right], \quad d = \sqrt{\Delta x_b^2 + \Delta y_b^2 + \Delta z_b^2}$$

在强化学习多任务奖励函数中，存在两个对立的驱动力：
- **目标到达奖励（Goal-reaching Reward）**：驱使机器人缩短与 Carrot 点的欧氏距离；
- **安全与避障惩罚（Collision/Cliff Avoidance Penalty）**：当深度图检测到近身存在断崖、陡坡或不可通行台阶时，惩罚前向速度，激励减速转向。

### 2. 短前瞻点（$L = 0.40\text{m}$）为什么能坚决下楼？
- **近端牵引梯度占绝对优势**：当 $L = 0.40\text{m}$ 时，3D 目标点紧贴机器人前方台阶下方（$\Delta x_b \approx 0.4\text{m}, \Delta z_b \approx -0.3\text{m}$），$d \approx 0.5\text{m}$，$\log(d+1) \approx 0.41$。
- **压倒断崖恐惧**：此时目标点在物理空间上处于“下一踏步”的落脚点范围内。策略网络判定目标为**触手可及的紧迫任务**，近端目标牵引奖励的梯度大幅压倒了相机所见阶梯断崖的避障惩罚。
- **输出动力学**：策略网络第一步即输出坚决的前进指令（$v_x \approx 0.50 \sim 0.55\text{ m/s}$），航向角速度近乎为零（$|\omega_z| \le 0.15\text{ rad/s}$），机器人直接踏下阶梯。

### 3. 长前瞻点（$L = 2.0\text{m}$）为什么绝对不下楼？
- **远端牵引衰减，避障占据统治地位**：当 $L = 2.0\text{m}$ 时，$d \approx 2.5\text{m}$，$\log(d+1) \approx 1.25$。目标点在遥远的下方空间。
- **视差深渊被判定为绝壁死胡同**：此时机器人眼前的相机俯视画面呈现大面积阶梯边缘与视差空洞，而两米外的目标无法提供足够的近距冲力。策略网络的碰撞评估模块将楼梯断崖判定为“前方存在严重垂直障碍/悬崖断头路”。
- **避障逃逸触发打转**：为了规避坠落和碰撞，网络激活逃逸策略，前向速度迅速归零并饱和输出反向角速度（$|\omega_z| \to 1.0\text{ rad/s}$），导致机器人在楼梯口原地急转或倒车后退。

### 4. 深度重映射的真实定位
- **消融结论**：实验证明，深度重映射并非“能否下楼”的必要条件。在 $L=0.40\text{m}$ 下，**纯原始深度图同样能够 $100\%$ 顺利下楼**；在 $L=2.0\text{m}$ 下，重映射深度图也无法挽救拒止。
- **辅助价值**：深度重映射将视差空洞与阶梯立面平滑为虚拟斜坡，其主要贡献在于进一步收敛航向抖动（将 $|\omega_z|$ 从 0.16 降低至 0.09 rad/s），并抑制两旁反光栏杆对视觉特征的扰动。因此，深度重映射作为可选的平滑增强算子，默认关闭即可实现极简无开销直通。

## 三、 关键技术模块详解

### 1. 3D 路径坡度门控 (StairsSlopeGate)
- **触发原理**: 沿全局 3D 路径在前向评估窗口（默认 1.2m）计算高程落差 $\Delta z$ 与投影斜率 $k = \Delta z / \Delta s_{2d}$。
- **下楼进入判定**: 当 $k < -0.20$（坡度下倾 $>11.5^\circ$）且 $\Delta z < -0.15\text{m}$（单阶落差）时，提前约 0.5m 触发 `is_descending_stairs = True`。
- **空间迟滞退出**: 当未来路径坡度回平（$k > -0.10$）且机器人平地行走超过 0.6m（`exit_dist_threshold`），退出下楼状态。
- **终点防死锁机制**: 当剩余路径不足 0.3m 且末端无下陡落差时，自动平滑释放楼梯状态，恢复平地防卡滞监测。

### 2. 楼梯前瞻锁存 (0.40m)
- **平地前瞻**: 默认支持 $0.5\text{m} \sim 2.0\text{m}$ 弯道曲率自适应（直道 2.0m 巡航，直角转弯 0.5m 贴边）；
- **下楼前瞻锁存**: 只要坡度门控触发下楼，前瞻距离立即强制锁存为 **$0.40\text{m}$**（`stair_lookahead_dist`），压制平地长前瞻，确保策略网络以最强近端目标牵引力平顺下梯。

### 3. 防后转安全护栏 (Anti-Reverse Guard)
- **途中下楼（距离终点 $>0.60\text{m}$）**：仅在目标真正落入身后（$dx_b < -0.15\text{m}$）时介入纠偏，严格杜绝转弯入梯口正常偏角时的误钳位；
- **路径切线纠偏**：沿规划路径切线方向引导朝向楼梯下行，杜绝沿误朝向推向侧墙；
- **终点收敛（距离终点 $\le 0.60\text{m}$）**：护栏自动退让，允许目标自然归零，引导平稳制动。

### 4. 速度控制与终点精准刹停
- **彻底移除 0.35m/s 硬限制**: 允许策略网络自由减速到 $0.0\text{ m/s}$ 刹停；
- **单向非负下楼防倒车边界**: $v_x \ge 0.0$，杜绝阶梯上挂倒档；
- **角速度限幅**: $\omega_z \in [-0.5, 0.5]\text{ rad/s}$，抑制台阶上剧烈甩尾擦碰扶手；
- **真实到达判定阈值**: `segment_arrive_threshold = 0.45m`（支持配置到 $0.50\text{m}$）。进入终点半径立即发布 `cmd_vel = 0`，清空路径，状态转移为 `GOAL_REACHED -> IDLE`。

## 五、 快速部署与操作参考

### 1. 同步与构建
```bash
# 本地推送至机器狗 (将 <ROBOT_IP> 替换为实际 IP)
./scripts/sync_stairs_to_go2w.sh <ROBOT_IP>
```

### 2. 启动命令
```bash
ssh agile@<ROBOT_IP>
cd ~/go2w_nav_ros2_ws

# 推荐标准模式: 弯道曲率自适应 + 梯口前瞻 0.4m (纯原始深度图直通，极简高效)
./start_nav_stairs.sh --curv-only

# 可选模式: 开启虚拟深度重映射对比测试
./start_nav_stairs.sh --curv-only --remapping

# 双因子模式 (曲率 + 局部视觉窄门 + 梯口前瞻 0.4m)
./start_nav_stairs.sh

# 自定义到达阈值 (如终点距离宽松度调至 0.50m)
./start_nav_stairs.sh --curv-only --arrive-thresh 0.50
```

### 3. 关键启动参数表
| 参数名称 | 环境变量 / CLI 选项 | 默认值 | 作用说明 |
| :--- | :--- | :--- | :--- |
| **楼梯前瞻距离** | `--stair-lookahead` | `0.40m` | **第一核心变量**：下坡锁存前瞻，策略近距目标牵引最优响应点 |
| **楼梯深度重映射** | `--remapping` / `--no-remapping` | `关闭(raw)` | 是否开启虚拟斜坡深度重映射 (默认关闭: 纯原始深度图) |
| **到达判定阈值** | `--arrive-thresh` | `0.45m` | 终点到达距离判定（实测 $0.45\text{m} \sim 0.50\text{m}$ 触发平稳制动） |
| **下楼最低限速** | `--stair-min-vel` | `0.0m/s` | 保底推进速度（设为 0.0，杜绝强制冲撞） |
| **楼梯坡度阈值** | `--stair-slope` | `-0.20` | 触发楼梯门控斜率阈值（提前约 0.5m 判定，平滑减速入梯） |
| **扶手防撞钳位** | `--stair-side-clamp`| `0.50m` | 两侧扶手栏杆最小保护距离（重映射模式下生效） |
| **起缩偏角门限** | `turn_angle_low` | `20.0°` | 路径偏角 $\le 20^\circ$ 时保持 $2.0\text{m}$ 前瞻，走廊轻晃不减速 |
| **全缩偏角门限** | `turn_angle_high` | `50.0°` | 路径偏角 $\ge 50^\circ$（直角弯及转入梯口）前瞻完全收缩至 $0.5\text{m}$ |
| **前瞻评估窗口** | `adaptive_window_dist` | `1.6m` | 评估前瞻窗口，提前约 0.8m 捕捉急转弯与梯口 |
| **出弯恢复速率** | `slew_rate_increase`| `0.8 m/s` | 出弯入直道后前瞻回血速度（平滑过渡，防打滑） |
| **自适应模式** | `--mode` | `curvature_only` | 默认 `curvature_only`，规避狭长走廊墙壁视觉误触发 |
